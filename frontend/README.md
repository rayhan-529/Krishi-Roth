# Krishi Roth — Frontend

React 19 + Vite single-page app. See the main [README](../README.md) and [docs/INSTALLATION.md](../docs/INSTALLATION.md).

```powershell
npm install
Copy-Item .env.example .env   # VITE_API_URL=http://localhost:5000
npm run dev                   # http://localhost:5173
npm run build                 # production build in dist/
```
